# Taura Anderson — Resume (React + Vite)

A modern, ATS-friendly two-page resume built with **React** and **Vite**. Designed for clean on-screen viewing and browser-based PDF printing (exactly two A4 pages) via a "Download PDF" button that triggers `window.print()`.

## Tech Stack
- React 18
- Vite
- CSS (white background, navy-blue accents, system typography)

## Preserved assets (untouched originals in `resume/` root; served copies in `public/`)
- `taura.jpeg` — profile photo
- `logo.jpeg` — app logo
- `PLP Academy.pdf` — Dart with Flutter Specialisation (Power Learn Project, April 2024)
- `Security-Cert.pdf` — Cybersecurity & Emerging Technologies Awareness Training (ICT Authority Kenya / Cyber Shujaa, June 12, 2024)

## Scripts
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production (output -> dist/)
npm run build

# Preview production build locally
npm run preview
```

## Deployment
Build output goes to `dist/`. Deploy the `dist/` folder to any static host (e.g., Render Static Sites, GitHub Pages, Netlify, Vercel).
